Questions, answered.

Here's what to expect while Scorpion Client is in development.

Can I download Scorpion Client now?

Not yet. This page is the UI preview; no client installers are available yet. The download section will be updated when real builds are ready.

Which Minecraft edition is Scorpion for?

Scorpion Client is being made for Minecraft Java Edition. Supported Minecraft versions and compatibility details will be announced closer to launch.

Which operating systems are planned?

Windows, macOS, and Linux are planned. Availability and packaging details may vary by platform when releases are announced.

Does this website use an external API?

No. The particles, RGB toggle, mobile navigation, and platform selection all run locally in your browser. The download controls remain placeholders until release links are supplied.
